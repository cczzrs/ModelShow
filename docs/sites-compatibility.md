# ModelShow → Sites 兼容性检查与未发布预览

检查日期：2026-09-12（UTC）。对象为当前 ModelShow 项目，沿用 Vite 7.1.5、Three.js 0.180.0 和 pnpm 锁文件。

结论：可以按 Sites 的静态产物契约准备和保存。现有应用完全在浏览器中执行，不需要添加服务器、数据库或云端图片上传。本次保留全部业务源码与功能；**本地浏览器通过不等于 chatgpt.site 远端运行已验收**，本次不部署、不公开发布。

## 兼容性问题与必要改动

| 项目 | 发现 | 必要改动 / 结论 |
| --- | --- | --- |
| Sites 静态入口 | 原项目没有 `.openai/hosting.json`。Sites 支持静态构建，要求指定公开产物目录并包含 `index.html`。 | 已注册未发布 Site，并配置 `static.directory: dist`。未声明 Worker 服务端、D1、R2 或额外能力。 |
| 静态资源路径 | 原构建的 JS、CSS、布局 Worker 使用 `/assets/…`；根路径可用，但路径前缀预览会指向错误位置。 | 添加 `vite.config.js` 的 `base: './'`，重新构建相对资源路径。`src/main.js` 的 `./example.json` 保持相对路径。 |
| 资源缺失的处理 | 这是单页工作台，但没有前端路由；将缺失 JS/JSON 重写为入口 HTML 会掩盖资源错误。 | 设置 `not_found_handling: '404-page'`。入口使用 `/` 或 `/index.html`；不添加不存在的页面路由。 |
| WebGPU | `src/view.js` 要求 `navigator.gpu`、GPU adapter 和真正的 WebGPU backend，明确不切换为 WebGL。 | 保留此契约。安全上下文、GPU 可用性和远端浏览器权限必须满足；不能将错误提示页当作完整 3D 验收。 |
| 布局 Worker | `src/view.js` 用 `new Worker(new URL('./layout-worker.js', import.meta.url), {type:'module'})`。 | 保留独立 Worker 和 1D/2D/3D/4D/5D/自动。构建必须包含 Worker 文件，远端需允许其同源加载和正确 JS MIME。 |
| 示例数据 | `src/main.js` 启动时请求 `./example.json`，失败会阻断后续启动。 | 保存并打包 `public/example.json` 的构建副本，检查响应为 JSON。 |
| 图标 | 仓库有 `favicon.ico`，入口没有显式引用，原构建没有携带图标。 | 引用既有图标，由 Vite 输出带内容哈希的资源；未更换品牌设计。 |
| 构建环境 | `dev.sh` 的 Node 回退路径仅属于本机；不能当作远端环境前提。 | 本机生成完整生产产物，再通过 Sites 标准打包保存。保留既有脚本和依赖锁定，不让托管端运行本机开发服务器。 |
| 首次下载量 | 主 JS 约 904 kB，gzip 约 259 kB，Vite 提示超过 500 kB。 | 这是体积提示，构建成功。没有通过删减 Three.js、标签、连线或输出画板消除警告。 |

## 浏览器条件与未确认项

- **CSP / iframe**：远端 CSP、`worker-src`、样式和下载策略尚未实测。业务代码无 `eval`/`new Function`；Three.js bundle 中存在未被本应用使用的 ScriptableNode 动态编译路径，不能据此要求放宽 `unsafe-eval`。本次未添加放宽安全策略的配置。
- **文件导入和图像输入**：仍通过用户选择本地文件、`file.text()` / `arrayBuffer()`、`createImageBitmap` 和 Canvas 在浏览器内处理。没有上传到服务器。原有 PNG/JPEG/WebP/APNG、方向、透明底色、RGB/灰度、位序、容量与资源限制保持不变。
- **模型及画板导出**：Blob 下载按钮保留，同时提供完整可复制 JSON。内置浏览器本次未返回下载完成事件，故不声称已验证文件落盘；JSON 生成及重新导入已通过。
- **全屏**：原生全屏与页面内全屏逻辑均保留；进入和退出后的控件/详情恢复已检查。未强制拒绝原生全屏，未单独覆盖所有 iframe 权限组合。
- **内存与持久化**：计算和图片内存属于访问者浏览器，不是 Sites 服务端 Worker 的内存额度。模型运行状态、图片仍只属于当前页面会话，刷新后不会由云端恢复。
- **实际发布验收**：首次获得发布授权后，需在最终 HTTPS 域名检查 WebGPU 首帧、Worker 六布局、JSON/MIME、文件选择、下载和全屏策略。本次没有远端生产 URL，也没有以私有部署冒充未发布预览。
