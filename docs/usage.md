# 使用 ModelShow · JKRD7

[返回项目入口](../README.md) · [文件与执行规则](model-format.md)

## RGB / JKM 标签

默认进入 JKM 的 COSMIC 工作区，右上菜单中的 RGB 按钮可切换到原 RGB 页面；RGB 顶栏的 JKM 标签可返回。RGB 保留原完整页面与输入数据提取、输出渲染、模型管理窗口。

JKM 右上菜单的显示类型按钮显示当前“单板”或“双板”，点击即可切换。默认单板，按钮未选中；点击选中后为双板，再次点击回到单板。已有缓存时恢复上次选择。双板：3D 场景位于左侧，右侧为模块桌面；拖动中间分隔条调整两区宽度，也可在分隔条获得焦点后按左右方向键调整。单板：3D 场景不显示顶部标题栏，直接铺满工作区背景，其它模块浮在场景上方；工具窗口仍可自由移动和调整大小。场景显隐通过程序坞控制，视图操作位于“场景控制”窗口。两种模式的菜单与竖向程序坞都固定在最右侧。较窄屏幕下，双板采用上下排列，单板继续使用场景背景。

右侧栏左边缘的竖向拖动条可调整整体宽度；菜单栏和程序坞之间的横向拖动条可调整上下占比。两处图标都会随侧栏宽度自动排列成一列或多列，各区域内容超出时独立滚动。侧栏宽度与上下占比在单板、双板之间共享，并在刷新后保留。拖动条获得焦点后可用对应方向键微调，Home／End 调到最小／最大值，Alt＋Home 恢复该项默认值；“还原”窗口布局不清除侧栏设置。

程序坞为场景、场景控制等 17 个模块提供独立矢量图标，点击可隐藏或显示对应窗口；程序坞向下延伸，图标较多时可滚动。拖动工具窗口标题可移动位置；双板下也可跨过分隔条放到场景区域或拖回工具区，3D 窗口位于左侧。拖动右下角调整大小，标题或缩放柄获得焦点后也可使用方向键，双板的 Ctrl＋左右键把工具窗口移到对应区域。标题右侧提供外观、收展与隐藏按钮。收起只保留标题，正文与当前数据仍保留。重叠的窗口可点击露出的区域置顶，或通过程序坞隐藏再显示。

点击右侧菜单中的“外观”，在“模块外观”的“设置对象”中选择“右侧菜单栏”或“右侧程序坞”。设置分为三组：“背景与轮廓”调整背景色、背景不透明度与圆角 R；“矢量图标”独立调整图标颜色、大小与不透明度；“文字”独立调整文字颜色、字体大小与不透明度。两者实时生效、独立保存，并在单板／双板之间共享。背景、图标与文字的不透明度互不影响，均可设为 0%；图标或字体变大时，列数会随可用宽度重新排列。恢复只作用于当前选中的对象。

默认布局与外观采用已从 Chrome 页面固化的配置，以 `html/config.js` 为准；各模块可有不同默认值。菜单和程序坞默认宽 80px、菜单占上下空间的约 35.4%，图标 30px、文字 15px。每个功能窗口可独立设置背景色、前景文字颜色、背景不透明度、圆角 R 和字体大小。窗口字体大小按 75%—200% 调整，100% 为原始字号；标题、正文、数字、表单与代码等字号按同一比例增减，保留原有大小层次。两种显示模式分别保存窗口位置、尺寸、显示与收展状态，共享模块外观；当前模式和双板分栏比例也保存在当前浏览器中，不写入 JKM、运行脚本或运行现场。切换单板／双板保留模型、运行状态与未保存的编辑内容。右上“还原”只恢复当前显示模式的默认窗口布局，保留另一种模式和已设置的外观；“恢复所选外观”只重置选中对象的全部外观设置。所有外观修改都会立即保存到当前浏览器的网站本地缓存（localStorage），刷新或重新打开后恢复，包含全局颜色、各模块外观以及菜单／程序坞的图标和文字设置。已有缓存优先保留；新默认值用于首次使用、缺失的设置项和“恢复所选外观”。

“设置对象”中的“全局外观”可修改 JKM 桌面背景、选中高亮、悬停反馈、键盘焦点、边框与分隔线，以及文字选中的背景色和前景色；还可开关“全窗口毛玻璃”，并按 0—40px 设置强度。毛玻璃作用于功能窗口、右侧菜单栏和程序坞，关闭后仍保留已选强度；效果取决于各模块的背景透明度。所有设置即时生效并保存到浏览器。模块已有的独立颜色与字号不被覆盖，RGB 页面保持独立。

“3D 网络”的背景颜色作用于原有场景渐变，不透明度只影响背景；保留原有中心雾化背景的配色与范围：中心色 #122630、边缘色 #08121f、边缘色位置 75%、不透明度 100%；雾化中心位于 3D 网络视图正中心（50% 50%）。文字颜色和字体大小作用于 3D 节点标签与传输文字，保留标签原有大小层次；标签默认白色并按 110% 显示。原有距离雾、节点与连线材质以及 RGB 页面的渲染样式保持不变。场景圆角用于普通单板和双板窗口；双板全屏渲染图铺满屏幕，不保留窗口边框与圆角；单板全屏保留各模块的外观设置。纯黑背景仍由场景控制切换；修改场景背景颜色或不透明度后，会退出纯黑模式以显示所选背景。

右侧菜单栏的“全屏”按钮按当前显示类型进入全屏，按 Esc 退出。“场景控制”集中放置名称显示、纯黑背景、视角复位和节点布局按钮，并显示鼠标操作提示；“输出渲染”通过程序坞中的“渲染”图标打开。点击程序坞中的“控制”图标打开场景控制，其中“连接线显示”逐行列出 J 运算线、K 运算线、触发通知线、来源定义线和输出观察线的当前颜色，各自的“已显示／已隐藏”按钮可独立切换显隐。颜色和显隐与“模块外观 → 连接线样式”双向同步，并使用同一份浏览器缓存。原场景中的操作条已移出。

在“模块外观”的“设置对象”中选择“连接线样式”，可分别设置 J 运算线、K 运算线、触发通知线、来源定义线和输出观察线的颜色、不透明度、连接长度与显隐。连接长度按原布局中两端节点的距离乘以 25%—300% 调整；多条线共用节点时综合约束，自连接不移动节点。反复调整始终以原布局为基准，不累积缩放，不改变连接关系，也不自动复位相机。

同一“设置对象”中的独立选项“节点样式”可设置输入入口、普通 JKI、输出观察，以及当前模型的各个 `pro.tag` 用途标签，支持颜色、25%—400% 大小、显隐和名称／次数显示。“节点用途”还提供“ex计算节点”和“无计算q节点”两类：前者为 `sources.ex` 非空的 JKI，后者为 `sources.ex` 为空或缺失的 JKI；分类包含输入入口，不含输出观察端点，也不随 q 的值改变。两类默认继承基础类别，修改时仅覆盖所调整的属性；用途标签设置优先于这两类和基础类别，有多个标签时使用模型顺序中第一个已设置的标签。隐藏节点会同时隐藏它的标签、相连的线与信号；名称显示还受“隐藏名称和次数”总开关控制。“ex计算节点”另有独立的“显示 x”开关和“x 颜色”：首次使用和恢复默认都直接读取 `scene.styles.nodes.computationTypes.ex.marker`，默认显示、白色；名称／次数显隐、用途标签及场景前景色均不覆盖 x 的设置，隐藏整个节点仍会隐藏 x。“恢复该类默认样式”会恢复 ex 类的样式与 x 默认；无计算q节点和用途标签通过“恢复继承样式”清除覆盖。连线和节点设置单独缓存于当前浏览器，跨模型保留已设置的分类和标签样式，不写入 JKM 或运行快照。

右上菜单的“状态”图标打开“显示状态”窗口，集中展示原底部状态栏的工作区、渲染平台、执行规则、计算平台、处理单元、节点求值、GPU 批次、任务和 EX 计数。状态在窗口隐藏时仍持续更新，页面底部不再保留固定状态栏。这两个新窗口也支持移动、缩放、收展、显隐与独立外观设置。

双板全屏保持只显示铺满屏幕的 3D 网络渲染图，标题栏及全部功能模块暂时隐藏。单板全屏显示整个左侧单板：3D 场景铺满背景，当前已显示的功能模块继续显示，已隐藏的模块保持隐藏，浮窗仍可移动、缩放和收展。两种全屏均隐藏右侧菜单栏与程序坞，仍可用鼠标操作场景。按 Esc 退出后恢复原单板／双板布局；全屏过程中不移动模块 DOM、不重建模型或渲染器。

两边的模型、q、队列、观察历史和界面配置独立。切换标签会在当前处理单元结束后暂停运行，返回后保留现场，可继续播放。两个标签都只执行 JKRD7，使用 JavaScript 或 WebGPU；RGB 标签不提供旧格式兼容。

## JKM：从示例开始

默认加载中央十选一 ASCII 示例。点击数字对应的输入入口，再点击“播放”，输出观察会得到该数字的 ASCII 位、数值和字符。也可以注入路径数组 `['G1.Q1', 'G1.Q2']` 对应的合法 JSON 写法：

```json
["G1.Q1", "G1.Q2"]
```

它表示同一批重叠请求，保留顺序与重复。入口点击或“注入此批”只追加通知，不直接改 q；暂停时可以继续追加输入。没有单独的 Xi／Yi 端口。

选择其他中央示例会加载其独立 JKM 定义。除默认 ASCII 示例外，按模型用途配置 watch／read 后观察输出；例如 1 bit 寄存器可将两者设为 `["G1.Q5"]`。节点详情通过网络点击或右侧“选择节点”树选择。树按 JKS／JKI 的包含关系缩进，点击 JKS 展开／收起，点击 JKI 查看详情；用途标签带边框并紧跟对应节点，同名 Q 仍按各自绝对路径区分。悬停行可查看完整路径。

加载完成后默认不选中节点，由用户点击网络或节点树选择。节点树支持上下键移动、左右键展开／收起或进入父子项、Home／End 移到首末项，Enter／空格选择节点。选中节点只同步选中状态，树保留手动展开／收起状态；打开或展开节点详情、正常计算更新也不会自动展开分支。初始展开层级在 `APP_CONFIG.view.inspector.tree.expandedDepth` 管理。

## JKM：运行和观察

- **播放／暂停**：开始或停止取出下一个处理单元；正在进行的完整事务不能从中间截断。
- **单步**：处理一条事件或一个任务。事务任务会完成整个事务后返回。
- **重置**：回到当前 JKM 定义的初值，清除本次运行状态和记录。
- **计算平台**：默认 JavaScript；WebGPU 执行可并行 EX 批，提交仍遵守中央顺序。显示状态窗口展示实际平台，GPU 批次统计只记录计算批次。
- **速度／跳过动画**：沿用原来的倍率滑杆和跳过开关；取消跳过可观察逐单元信号，不改变队列语义。

队列面板分开显示事件与任务。事件优先；同一节点可同时存在多个任务。详情展示节点 q、完整定义、触发来源、前置登记、EX／seed、publish 和 all 到达记录。展开队列下方区域查看运行中的登记轮。

JKM 的“节点详情”窗口使用固定标题栏，右侧上下箭头控制整个模块的收展；其他窗口保持各自位置。内容分为“基本状态、计算 EX、触发与发布、完整定义”四组，可分别展开；默认只展开基本状态，节点名称与当前 q 都在这一组中。收展按钮与分组支持 Enter／空格操作，切换节点或 RGB／JKM 时保留当前折叠选择。模块默认位置、尺寸、显隐和收展配置位于 `APP_CONFIG.desktop.windows`，节点详情内部的分组默认值位于 `APP_CONFIG.view.inspector.sections`。

基本状态分别列出当前 q 和初始 q，完整定义中的 q 是模型初值；空 EX 明确提示不读取来源和 seed。all 到达记录的 null／0／1 分别代表未到达／首次到达／重复到达，不代表来源 q。

“输出渲染 → 观察配置”分别填写 watch 和 read 的绝对路径数组。watch 指定订阅谁，read 指定收到通知时按什么顺序取值；应用配置会从当前定义初值重新开始。输出画板每行对应一条输出，绿色为 1、灰色为 0。初始化时显示等待通知。

## JKM：模型、脚本和快照

“模型管理”可打开 JKM 文件，或编辑 JSON 后“校验并加载”。失败时保留当前模型。“下载当前定义”只保存初始定义，运行现场另存。共享模型池的操作见[模型池说明](hosting.md)。

“运行脚本”接受 JKRD7 §9.4 文件。先确认页面“当前 JKM 文件标识”与脚本的 model 一致；浏览器执行当前已加载的模型。点击“从初值执行”后，按脚本的 observe 和 batches 运行，每批静止后才进入下一批。长时间循环会触发运行预算限制，已形成的状态仍可检查。

“现场快照”可捕获当前处理单元边界的状态、下载 JSON 或读取文件恢复。先加载相同 JKM，并设置相同输出观察配置，再恢复快照。恢复包含 q、all 记录、登记轮和双 FIFO，不包含此前输出历史与界面状态；恢复后通过单步或运行继续。

“下载 JSONL”保存完整标准执行记录，只有 inject、notify、q、output 四类对象。页面展示行数的限制不裁剪计算队列，也不改变下载记录。

## JKM：图片生成输入脚本

“图片转输入”打开本地 PNG／JPEG／WebP，选择位 0、位 1 对应的两个已声明输入入口，设置灰度阈值和取样像素上限。按行从左上角提取灰度位，每个像素形成一个输入批。

点击“生成运行脚本”只生成脚本；核对内容后再执行。它使用独热入口的通知表达 0／1，不增加模型字段、不写 q、不补充隐含端口。位入口应与当前模型的实际用途一致；1 bit 寄存器示例可用置 0／置 1 入口观察结果。

## RGB：输入数据提取

RGB 默认模型为 `RGB_3X3`，输入为 3×3 像素、每像素 RGB 三通道、每通道 8 位，共 216 位。216 个 M_REG 组合保存这些位，完成节点等待整帧后通知输出。

点击“输入数据提取”，可选择内置图片或本地 PNG／JPEG／WebP。窗口保留原图片预览与选区：调整宽、高、X、Y，拖动选区，使用滚轮缩放，按住空格拖动或中键拖动平移。支持 RGB／灰度、逐像素／逐通道排列、每字节 LSB／MSB 优先以及透明背景底色。

提取位数必须与当前绑定输入位数相等。点击填入后，主页面输入框得到数字 0／1 数组；“发送信号”按 `inputs` 中每位的 `[置0入口, 置1入口]` 选择路径，再点击播放处理通知。提取和映射不会直接改写 q。默认选区为 3×3、RGB、逐像素、LSB 优先；修改编码或尺寸时需要相应调整模型与绑定。

## RGB：输出渲染与灯阵

“输出渲染”保留原行列、画板大小、逐灯 RGB 通道、打包位、位序调整、亮度换算与批量绑定功能。每个通道可用固定值或绑定 `observe.read` 中的真实 JKI 路径；输出通知到达后读取的位决定灯的颜色。

默认 3×3 灯阵已按输入的 RGB 顺序绑定，**显示画板默认关闭**。勾选“显示画板”后，原 3D 灯阵出现在网络输出侧。选择灯可检查 RGB 读取值，或回到输出窗口编辑。换布局、调颜色与显示开关不会生成模型通知。

## RGB：模型管理与配置文件

RGB 模型管理保留原选择器、JSON 编辑、导入下载和共享池布局，但模型仍只接受 JKRD7 JKM。自定义模型通过“输入与输出绑定”设置 `inputs`、`observe.watch` 和 `observe.read`；应用绑定会重新从模型初值运行。

“下载 RGB 配置”保存独立 `.rgb.json`，包含对应模型名称、输入／观察绑定和灯阵配置。恢复时先加载对应 JKM，再“导入 RGB 配置”；配置中的路径必须存在，灯阵使用的位必须包含在 `observe.read` 中。导入配置会恢复模型初值，不恢复此前 q 或队列。JKM 下载与共享池只保存模型定义，不夹带这些界面字段。

同一页面内会按模型定义与绑定缓存灯阵配置，切换回来可继续使用；页面刷新后的保留需依靠另存的 `.rgb.json`。该配置文件属于 ModelShow 界面，不是 JKRD7 运行快照。

## 网络视图

沿用原 1D、2D、3D、4D、5D 与自动布局，默认 5D。保留立方体节点、漂浮曲线、箭头、网格和信号动画。左拖旋转、右键／中键拖动平移、滚轮指向缩放；“重置视角”恢复取景，“隐藏名称和次数”控制标签，“纯黑背景”和“全屏”沿用原效果。布局切换不修改运行状态。

场景 WebGPU 不可用时显示 Canvas 2D 状态，计算仍可使用 JavaScript。布局、颜色与降级说明见[场景与渲染](rendering.md)。
