| 范围 | 改动前 | 本次实现 |
| --- | --- | --- |

| 输入 | Xi 来源事件入队，初始 Xi 为 0 | send 立即更新 Xi，每项形成同编号有状态输入副本任务；首次 send 前 Xi 不可读 |
| 调度 | 一次来源通知可能执行多个目标 EX | Xi.FIFO 优先值 1、Qi.FIFO 优先值 5；一个任务只完成一个原子 EX 和即时传播 |
| Qi_J0 到达 | 来源缓存与待处理通知 | 收齐即锁存进独立任务并清空到达集合；下一组数据与旧任务分开保存 |
| 结构校验 | 历史来源约束与到达 DAG | 排除合法自引用后的全部 Q 来源连接必须为 DAG；校验输入副本、来源数和被引用数 |
| Yi | 当前绑定 q 与发布记录分开展示 | 只消费当次发布事件；初始化未输出，数值 0 与同值事件均保留 |
| 快照 | 保存 q，未保存待执行计算任务 | 同一任务边界保存当前 q 和两条剩余 FIFOS；恢复缺失 Xi 的任务结束但不执行 EX |
| 指纹 | 历史结构/状态成员载荷 | 中央 V4 载荷：format_md5 包含 initial_q 实际值；md5 再包含 FIFOS 和 created_at |
| 展示配置 | 画板混入模型导出 | JK display 只保存 show；RGB 画板使用独立 JSON 导入/导出 |
| 运行限制 | 10,000 项队列容量门槛 | 保留全部计算任务；每帧预算和最多 10,000 次取任务限制只调节界面调度 |
| 示例与设计 | 旧模型及历史实现说明 | 新 V4 模型池种子、标准快照夹具、当前接口与恢复边界文档 |

## 保留的语义限制

标准快照不保存 Xi 当前值、无状态临时结果、未收齐到达集合、Yi 历史或动画进度，不能当作完整运行现场检查点。多个输入复制任务可读取同一个最新 Xi，任务数量不代表输入历史被逐项保存。

动态节点创建、连接、释放和按需扩展等待区仍属于中央的扩展设计；本次实现没有将静态双队列或显示历史替代该扩展。
